# Awesome Design

Collection from https://github.com/VoltAgent/awesome-design-md (MIT). Each brand has `design-md/<brand>/DESIGN.md` (the design system) and a short `README.md`.

## How to use

1. Identify the brand/style the user wants. If unspecified, list a few fitting options from below and pick the closest match, stating the choice.
2. Read `design-md/<brand>/DESIGN.md` and follow its tokens, typography, spacing, component and do/don't rules when building the UI.
3. Don't copy logos, trademarks, or proprietary assets — use the design language only.
4. To bring it into a project, copy the chosen `DESIGN.md` to that project's root.
